# 安全与密钥管理

## 1. 目标

为 local、dev、test、prod-like 建立一致的基础安全边界，重点防止凭证泄露、过度授权、管理端口暴露和供应链漂移。

## 2. Secret 原则

- Git 中禁止出现明文密码、Token、私钥、age identity 和完整连接凭证。
- Manifest 只保存 Secret 引用、无敏感值模板或 SOPS 加密内容。
- Secret 的生成、加密、解密、轮换和销毁必须有 Runbook。
- 不同环境使用不同凭证和 age recipient。
- 禁止复制 `prod-like` 凭证到低环境。
- CI 不输出解密后的 Secret。
- 备份中的 Secret 或配置也必须加密。

## 3. Phase 01 Secret 方案

根据 [ADR-009](../adr/ADR-009-使用SOPS与age管理密钥.md)，Phase 01 使用 SOPS + age：

- SOPS `3.13.0`。
- age `1.3.1`。
- Git 保存 `.sops.yaml` 密文、公钥 recipient 和规则。
- age identity 保存在仓库外的受控位置。
- CI 默认验证密文结构，不解密真实环境 Secret。
- External Secrets 保留为后续演进方向，不在 Phase 01 引入。

具体命令与恢复要求见 [SOPS + age 工作流](../../security/sops/README.md)。

手工创建 Secret 只能作为临时 PoC，必须记录漂移、有效期和清理任务，不作为长期方案。

## 4. RBAC 与 ServiceAccount

- 每个应用或组件使用独立 ServiceAccount。
- 默认不授予集群管理员权限。
- Namespace 内权限优先于 ClusterRole。
- 运维脚本不得默认使用长期高权限 Token。
- CI 部署身份与人工运维身份分离。
- 权限变更需要记录原因和影响范围。
- `cluster-admin` 绑定默认被策略校验拒绝，确需例外时使用 `infra.mom.io/policy-exception` 注解并记录原因。

## 5. 工作负载安全

以下配置默认被策略校验拒绝：

- `privileged: true`。
- `hostNetwork: true`。
- `hostPID: true`。
- `hostIPC: true`。
- `hostPath` Volume。

确需使用时必须：

1. 添加 `infra.mom.io/policy-exception` 注解。
2. 说明原因、影响范围、停止条件和替代方案。
3. 在 PR 中由人工审查。
4. 在使用结束后移除例外。

## 6. 网络边界

- 数据库、中间件管理端口默认只允许集群内部访问。
- 外部入口统一通过 Ingress 或受控管理通道。
- 管理控制台不直接暴露公网。
- 后续通过 NetworkPolicy 明确应用到 PostgreSQL、Redis、Nacos、RocketMQ、Seata 和观测组件的允许关系。
- 故障演练不得绕过长期安全边界后忘记恢复。

## 7. TLS 与证书

- Ingress 使用 TLS。
- 证书来源、有效期和轮换方式必须记录。
- 私钥不得进入 Git。
- 证书更新需要验证应用连接、Webhook 和管理入口。
- 证书过期应有提前告警。

## 8. 镜像与供应链

- 所有镜像必须使用显式 Tag 或 Digest。
- 禁止 `latest`、`stable`、`main`、`master`、`edge`、`snapshot`、`nightly`、`canary` 等浮动 Tag。
- `prod-like` 使用 Digest。
- 记录镜像仓库、上游项目和许可证。
- 限制从未知公共仓库直接拉取镜像。
- 后续引入镜像漏洞扫描和 SBOM。
- 第三方 Chart 或 Manifest 修改必须记录来源和 Diff。

## 9. 敏感日志

禁止记录：

- 密码、Refresh Token、API Key。
- 私钥、age identity 和完整证书内容。
- 数据库连接串中的密码。
- 用户隐私和真实生产数据。

日志脱敏由应用和基础设施共同负责；Collector 不应被视为唯一脱敏层。

## 10. 安全校验门禁

当前 CI 包含：

- Gitleaks 常见凭证扫描。
- 私钥、证书库和 age identity 文件检查。
- Kubernetes Secret 必须为 SOPS 密文。
- 无 Tag、浮动 Tag 和 `prod-like` 非 Digest 镜像检查。
- `cluster-admin` 和无限制 ClusterRole 检查。
- `hostNetwork`、`hostPID`、`hostIPC`、`privileged`、`hostPath` 检查。
- Kustomize 渲染和 Kubernetes Schema 校验。

后续增加：

- 镜像仓库白名单。
- 镜像漏洞扫描和 SBOM。
- Pod Security Standards。
- 更细粒度 NetworkPolicy 验证。

## 11. 事件处置

发现凭证泄露时：

1. 立即停止继续使用该凭证。
2. 轮换并撤销旧凭证和相关 age recipient。
3. 检查 Git 历史、CI 日志和制品。
4. 判断是否需要清理 Git 历史。
5. 检查访问日志和异常行为。
6. 重新加密受影响文件并验证旧 identity 行为。
7. 记录影响、处置和改进措施。

仅删除当前文件并不能消除 Git 历史中的泄露。
