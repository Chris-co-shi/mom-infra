# MOM Infrastructure 文档中心

本目录是 `mom-infra` 的架构、环境、计划、运行手册、容灾和架构决策权威入口。

> 所有文档新增、修改、重命名和整理统一在 `agent/complete-chinese-docs` 分支进行，详见 [文档维护约定](文档维护约定.md)。

## 文档职责

| 类型 | 回答的问题 |
|---|---|
| 总体架构 | 基础设施由哪些部分组成，如何协作 |
| 环境治理 | local、dev、test、prod-like 如何保持一致并晋级 |
| 实施计划 | 按什么顺序落地，什么结果算完成 |
| 运行手册 | 某项运维操作如何执行、验证和回滚 |
| 容灾文档 | 数据和集群故障后按什么顺序恢复 |
| 故障演练 | 如何在受控范围内验证高可用和恢复能力 |
| ADR | 某项关键基础设施决策为什么这样选择 |

## 文档维护原则

1. 根 README 负责项目门面和快速入口，不复制详细运行手册。
2. 运行手册必须包含前置条件、影响、执行、验证、回滚和证据。
3. 备份方案必须包含恢复测试，只有备份没有恢复验证不算完成。
4. 组件版本、镜像、Chart 和许可证必须有唯一登记来源。
5. 文档描述必须区分“当前已实现”和“后续计划”。
6. 基础设施变更与文档不一致时，不允许静默偏离。
7. 关键技术选择变化时使用新的 ADR 替代旧 ADR。

## 当前阶段

当前处于 Infra Phase 01：完成版本矩阵、环境模型、校验门禁、命名空间和可观测性最小闭环。在这些能力通过验收前，不直接进入类生产中间件集群部署。
