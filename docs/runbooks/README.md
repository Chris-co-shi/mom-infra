# Runbooks

Runbooks will be added incrementally for:

- cluster bootstrap and node replacement
- middleware deployment and health verification
- certificate renewal
- backup and point-in-time recovery
- rolling upgrade and rollback
- Redis, PostgreSQL, Nacos, RocketMQ, and Seata failure recovery
- OpenTelemetry pipeline and dashboard troubleshooting

Every runbook must include prerequisites, impact, verification, rollback, and evidence collection.
